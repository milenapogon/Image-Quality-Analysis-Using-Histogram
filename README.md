# Analiza jakości zdjęć na podstawie histogramu

## Opis

Program analizuje jakość obrazu na podstawie histogramu, sprawdza jasność, kontrast i prześwietlenie, a następnie ocenia zdjęcie i może je automatycznie poprawić.

## Funkcje

* wczytanie obrazu z internetu
* histogram (grayscale + RGB)
* ocena jakości (0–3)
* automatyczna poprawa obrazu

## Ocena jakości

* 3 - dobra
* 2 - średnia
* 0–1 - słaba
